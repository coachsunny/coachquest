📘 1 分鐘免費綁定 Cloudflare KV 資料庫教學

Cloudflare Workers 預設是無狀態（Stateless）邊緣運算。只要綁定 Cloudflare 免費提供的 KV 資料庫（每天 10 萬次讀取 / 1 千次寫入完全免費），學員的練習對話就會全球永久持久保存！

步驟 1：建立 KV Namespace

  1. 登入 Cloudflare Dashboard。
  2. 點擊左側導航選單的 Storage & Databases ➔ 點選 KV。
  3. 點擊右上角 Create a Namespace 按鈕。
  4. Namespace Name 填寫：COACHQUEST_KV，點擊 Add。

步驟 2：綁定到 CoachQuest Worker

  1. 在左側導航選單點選 Workers & Pages ➔ 點進 coachquest。
  2. 切換至 Settings 分頁 ➔ 點選 Variables and Secrets（或 Bindings）。
  3. 在 KV Namespace Bindings 區塊點擊 Add binding。
  4. Variable name 填寫：COACHQUEST_KV。
  5. KV namespace 下拉選單選取剛才建立的 COACHQUEST_KV。
  6. 點擊 Save and Deploy 即可！

✅ 完成後重新整理本管理看板，上方警告將自動消失，並開啟永久雲端同步功能！
